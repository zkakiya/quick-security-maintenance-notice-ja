# quick-security-maintenance-notice-ja

**脆弱性対応時に取り急ぎ使える、一時閉鎖告知HTML（日本語）**

Webサイトの脆弱性対応などで、緊急にサイトを一時閉鎖する際に使用するシンプルな日本語の告知ページです。

取り急ぎ設置することを目的とし、HTMLとCSSを単一ファイルにまとめています。

外部ライブラリ・画像・JavaScriptなどは使用していません。

レスポンシブデザインに対応しており、PC・スマートフォンなど、画面サイズの異なる端末でも表示できる構成です。

## 使い方

1. `index.html` をダウンロードします。
2. 必要に応じて告知文を編集します。
3. Webサーバーに配置し、元のサイトの代わりに表示されるよう設定します。

### 告知文の変更

`index.html` 内の以下の部分を編集してください。

```html
<h1>一時閉鎖のお知らせ</h1>
<p>脆弱性対策のため一旦閉鎖します。</p>
```

### 色・文字サイズの変更

ファイル冒頭のCSSで変更できます。

```css
:root {
    --main-color: #333; /* 文字色 */
    --background-color: #f9f9f9; /* 背景色 */
    font-size: 16px; /* 基本の文字サイズ */
}
```

## 設置時の注意事項

### HTTPステータスコード

このHTMLを配置するだけでは、HTTPステータスコードは変更されません。

一時的なサービス停止を通知する場合は、Webサーバー側で `503 Service Unavailable` を返すことを推奨します。

復旧予定が明確な場合は、`Retry-After` ヘッダーの設定も検討してください。

### セキュリティ対策

**このHTMLを設置するだけでは、脆弱性への対策にはなりません。**

元のWebサイトやアプリケーションへのアクセス遮断は、別途適切に実施してください。
